# Кайлаас — приватный концепт сайта

Персональный демо-сайт для кандидата `C-070` из рабочей базы лидов. Сайт предназначен для приватной демонстрации и не является официальным сайтом ресторана.

## Команды

```bash
npm install
npm run dev
npm run build
```

## Источники фактов

- Яндекс Карты: https://yandex.com.ge/maps/org/kaylaas/229005420861/
- 2ГИС: https://2gis.ru/spb/firm/70000001102598696
- Официальный канал из карточки Яндекса: https://vk.ru/kailaash
- Рабочий бриф: `RESEARCH.md`

## Материалы

- `public/hero-kailaash.webp` — оригинальное сгенерированное изображение для концепта; оно не показывает реальный интерьер или блюда ресторана.
- Фото из карт не используются. Их публикация требует отдельного согласования с владельцами материалов.

## Ограничения

- Перед публичным запуском ресторан должен подтвердить тексты, часы работы, контакты и права на материалы.
- 2ГИС удалил старую карточку 14.08.2026; Яндекс на дату проверки показывает действующую карточку и свежие отзывы. Перед обращением нужно подтвердить работу ресторана по публичному номеру.
